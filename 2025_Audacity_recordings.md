# Preparing animals
Males should be injected ~10-12 hours in advance of recordings with 400 IU of HCG for a large male XL. After injection, place one male alone in a tank with 2/3rd full of water, cover and keep in a quiet place until you are ready to record.

Set up the recording using Audacity and a hydrophone as described below. Completely submerge the hybrophone in the tank with the male and then add a female to the tank. This should be done in low light conditions and the screen of your laptop should not be in view of the tank.

The recordings should be set to auto-record if the male calls. I usually do 4 males and give each one ~20 minutes to vocalize before trying the next one.

# Setup
Plug the amplifier into your laptop and the hydrophone into the right-most jack. Also install the 9volt battery in the hydrophone. Before adding th hybrophone to the tank, test it to make sure it is recording.


# Audacity recordings

In audacity "Preferences" and "Audio Setup", need to make sure that the input device is set to audiovox so that the hydrophone is being used instead of the built-in mic
